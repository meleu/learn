OPA CLI Cheat Sheet

The opa commands worth keeping at hand. Verified against OPA 1.19.0 on this machine.

When a policy misbehaves, do not reread the rule. Print the document and find the key that is missing or wrong. Debugging Rego is nearly always "which key is undefined, and why".

The loop

opa eval — the workhorse

FlagDoes
-d, --dataLoad a .rego policy, a .json/.yaml data file, or recursively a whole directory of them.
-i, --inputThe file that becomes the input global.
--format prettyHuman-readable output. Without it you get a verbose result wrapper.
--format jsonMachine-readable, with binding metadata.
--explain fullPrint the full evaluation trace. Reach for it when a rule is undefined and you cannot see why.
--failExit non-zero when the result is undefined. Useful in scripts.
--fail-definedExit non-zero when the result is defined — the shape a "deny" check wants.
-b, --bundleLoad a directory or tarball as a bundle (policies + data together).

Reading the output

You seeIt means
{}The package exists but every rule in it was undefined. Usually a condition that did not hold — not an error.
undefinedYou queried a single node and it has no value. Same cause, narrower question.
"allow": falseA real value is present. Something — usually a default — supplied it.
[]A multi-value (set) rule ran and nothing contributed. An empty set is a value, unlike undefined.
rego_parse_error: `if` keyword is required before rule bodyRego v0 syntax. The snippet predates OPA 1.0; add if.
rego_type_error: …Caught at compile time, before evaluation. Often a safety violation — an unbound variable.

Other opa subcommands

CommandUse
opa runInteractive REPL. The fastest way to try a built-in function. Load context with opa run policy.rego.
opa testRun Rego unit tests — rules named test_*. Add -v for per-test detail.
opa checkCompile without evaluating. A fast syntax and safety check for CI.
opa fmtCanonical formatting. -w writes in place; --diff shows the change. Also the quickest way to spot v0 syntax.
opa depsShow what a query depends on. Useful on a policy set you inherited.
opa versionConfirm you are on OPA ≥ 1.0, i.e. Rego v1.
