Rego & Conftest

Course Index

Everything written so far, in reading order. Lessons build on each other; the references are written to be jumped into cold and kept open in a second tab.

The whole course hangs off one sentence: a .rego file is a set of rules that build a JSON document from input data. Every lesson below is that sentence getting more precise.

Lessons

  • Lesson 1 Rego Builds a JSON Document

    Why Rego exists, what "decoupled policy" actually buys you, and the opa eval command that lets you watch the document get built.

  • Lesson 2 Many Rules, One Set

    Why two rules of the same name conflict, and how contains turns a pile of independent checks into one collected set of messages — the shape every real policy has.

  • Lesson 3 The Conftest Contract

    Conftest adds no new language — only four conventions: where the policy lives, what package it declares, what the rule is called, and what it produces.

Reference

  • Reference 1 Glossary

    The vocabulary, defined once and used consistently everywhere else. Terms marked † are the ones people routinely get wrong.

  • Reference 2 OPA CLI Cheat Sheet

    The opa commands worth keeping at hand — eval flags, the debugging loop, and the exit-code shapes for scripts.

  • Reference 3 Conftest Cheat Sheet

    The contract, the flags, the exit codes, and conftest parse — the one command that makes an unfamiliar config format tractable.
