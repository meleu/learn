Unity + TDD cheat sheet

The loop, the skeleton, the Makefile, and the assertions you'll actually use.

The loop

  1. Write a test for the next small requirement.
  2. Make it compile: add only the declaration or stub the compiler and linker demand.
  3. Run it and see it fail, and check that the failure message is meaningful.
  4. Write just enough code to make it pass.
  5. Refactor the production code and the tests, staying green.

After Learn Go with Tests, “Hello, World”.

Test file skeleton

#include "unity.h"
#include "hello.h"           /* the module under test */

void setUp(void) {}           /* runs before EVERY test; required */
void tearDown(void) {}        /* runs after EVERY test;  required */

void test_thing_does_x(void)
{
    TEST_ASSERT_EQUAL_STRING("expected", actual());
}

int main(void)
{
    UNITY_BEGIN();
    RUN_TEST(test_thing_does_x);   /* unlisted tests never run */
    return UNITY_END();            /* exit status = number of failures */
}

Makefile

CC       := cc
CFLAGS   := -std=c17 -Wall -Wextra -Wpedantic -g
CPPFLAGS := -Ivendor/unity

test: build/test_hello
	./build/test_hello

build/test_hello: test/test_hello.c vendor/unity/unity.c | build
	$(CC) $(CPPFLAGS) $(CFLAGS) $^ -o $@

build:
	mkdir -p $@

clean:
	rm -rf build

.PHONY: test clean

Assertions

Always expected first, actual second. Every assertion has a _MESSAGE variant that takes an extra string. Full list: Assertions Reference.

MacroChecks
TEST_ASSERT_TRUE(c) / _FALSE(c)a condition
TEST_ASSERT_EQUAL_INT(e, a)signed ints (also _UINT8, _INT32, _size_t, …)
TEST_ASSERT_EQUAL_HEX8(e, a)same as above, but failures print in hex
TEST_ASSERT_EQUAL_STRING(e, a)NUL-terminated strings, compared character by character
TEST_ASSERT_EQUAL_STRING_LEN(e, a, n)the first n characters
TEST_ASSERT_EQUAL_MEMORY(e, a, n)n raw bytes
TEST_ASSERT_EQUAL_INT_ARRAY(e, a, n)n array elements
TEST_ASSERT_EQUAL_PTR(e, a)pointer identity (same address)
TEST_ASSERT_NULL(p) / _NOT_NULL(p)a pointer
TEST_FAIL_MESSAGE("…")fail unconditionally
TEST_IGNORE() / TEST_IGNORE_MESSAGE("…")skip this test
