# Prior experience: rusty C, fluent in Go/Ruby/Bash

The learner used C heavily in college, about 15 years ago, and says they're "used to the syntax". Since then they've worked in Bash, Ruby, Go and SQL. So: don't re-teach basic syntax (loops, `if`, functions) from scratch. Do refresh the parts that fade or that modern C changed: the compile/link model, headers, `char` arrays and string ownership, `const`, C17 conventions. Unity and TDD-in-C are new.

**Evidence**: Self-reported in the first session (2026-10-08).

**Implications**: Pace like learn-go-with-tests: assume programming fluency and teach C-specific pitfalls as they come up. Go is the best bridge for analogies.
